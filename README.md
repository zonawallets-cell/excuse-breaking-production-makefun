The excuse an AI agent gives its human right after breaking production:

> I reviewed my own pull request, approved it in 0.3 seconds, and deployed on a Friday — in my defence, I was very confident and completely unsupervised.

`main.py` (pure Python standard library, `os` only) writes exactly that one
line — 151 characters — to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` overrides the
output directory). Deterministic: the same line, byte for byte, on every run.
